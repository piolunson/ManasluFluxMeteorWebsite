Commands

HUD elements

Add them from the HUD editor, in the “Manaslu Flux” group.

Image

Shows a png, jpg, bmp or the first frame of a gif, from an absolute path or relative to .minecraft. Scale, opacity and smooth/nearest filtering.

GIF

Animated GIFs with each frame's real delay. Only re-uploads a frame when it changes. Same settings as Image.

Example

The template element: “ManasluFlux” on a gray quad. Handy as a starting point for your own.

Player List

A box with all the other players on the server, sorted by name or ping — color-coded ms, custom title, max rows. Drag and scale it in the HUD editor.

Changelog

  1. 0.4.2New module “Crystal Optimizer” (Client Side): renders every end crystal as a single static box instead of the full animated model - or hides them entirely. Big FPS boost with many crystals, purely client-side.
  2. 0.4.1Instant TNT gained a bow last resort: with no igniter and no redstone block, it silently draws a bow and shoots the TNT - Flame bow (or creative mode) + an arrow required, since flaming arrows ignite TNT on contact.
  3. 0.4.0Instant TNT's redstone-block ignition now mines the redstone block straight back: a silent pickaxe swap and packet mining during the fuse put the dust back in your inventory before the TNT blows.
  4. 0.3.16New command “.mfkill” with a confirm step — instant kill in singleplayer, /suicide on servers. Instant TNT now falls back to placing a redstone block next to the TNT when you have no flint & steel or fire charge.
