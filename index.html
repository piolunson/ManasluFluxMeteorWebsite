Commands

HUD elements

Add them from the HUD editor, in the “Manaslu Flux” group.

Image

Shows a png, jpg, bmp or the first frame of a gif, from an absolute path or relative to .minecraft. Scale, opacity and smooth/nearest filtering.

GIF

Animated GIFs with each frame's real delay. Only re-uploads a frame when it changes. Same settings as Image.

Example

The template element: “ManasluFlux” on a gray quad. Handy as a starting point for your own.

Player List

A box with all the other players on the server, sorted by name or ping — color-coded ms, custom title, max rows. Drag and scale it in the HUD editor.

Server Info

Your server's name and address, online player count and your live latency, color-coded. Dark box, rows toggle individually.

Session Info

In-game day number, HH:MM clock, weather (Clear/Rain/Thunder) and the biome you are standing in — the same overworld clock the .mfday command uses.

Kill Counter

Session combat tracker: kills (players and/or hostile mobs, friends excluded), deaths and computed K/D. Auto-reset on world or dimension change.

Changelog

  1. 0.7.0New module: Discord RPC — fully customizable Rich Presence. One-click presets (Crystals, PvP, Mining, Exploring, Building, AFK), editable Line 1 / Line 2 with placeholders ({player}, {server}, {ping}, {pos}, {dimension}, {server}, {cps}, {version}, {health}), large image name & text, optional small image, elapsed-time timer, update interval, and a built-in crystals-per-second counter. Set your own Discord Application ID to change the name shown by Discord and use your own images (default: Meteor's app).
  2. 0.6.0Full port to Minecraft 1.21.11 + Meteor Client 1.21.11: every module, command, HUD element and both mixins re-mapped to the new API, the bundled Baritone swapped to the 1.21.11 Fabric build, and the Image/GIF HUD elements rewritten onto the new blaze3d texture path (async decoding). Nothing added or removed — this is the compatibility release.
  3. 0.5.3New Anti Drop Lagback module: counts rubberband corrections (server position syncs that snap you back) inside a time window, and when the cap is passed it pauses every other active module for a set amount of ticks so the cause stops — then resumes them. Chat notifier included.
  4. 0.5.2Crash fix: the Client Block Entities mixin declared a wrong parameter type, so the mixin failed at startup and crashed the game on launch (0.5.0/0.5.1). Now uses the exact descriptor and the game boots fine.
  5. 0.5.1New Auto Chat Clear module: automatically does the vanilla F3+D chat clear after every N received messages - keeps the backlogged chat empty on busy servers without manual keypresses. Scrollback history stays (optional wipe), nothing is sent to the server.
  6. 0.5.0New Client Block Entities module: pick any block entity types (chests, signs, beacons, spawners...) and their rendering becomes client-side only - replaced by a static box or hidden entirely, like Crystal Optimizer but for everything. The block itself still renders normally.
  7. 0.4.10Crash fix: opening the Meteor GUI in the main menu no longer crashes ("Components not bound yet" - category icons now use the same pre-bound item construction Meteor itself uses).
  8. 0.4.9Two new top-bar tabs in the Meteor GUI: Notepad (multiple free-text note pages) and To Do (checkbox task list with a n/m-done counter). Both save to disk and survive restarts.
  9. 0.4.8Three new HUD elements: Server Info (server/address + live ping), Session Info (in-game day, clock, weather, biome) and Kill Counter (session kills/deaths/K-D). HUD count 4 → 7.
