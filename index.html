Commands

HUD elements

Add them from the HUD editor, in the “Manaslu Flux” group.

Image

Shows a png, jpg, bmp or the first frame of a gif, from an absolute path or relative to .minecraft. Scale, opacity and smooth/nearest filtering.

GIF

Animated GIFs with each frame's real delay. Only re-uploads a frame when it changes. Same settings as Image.

Example

The template element: “ManasluFlux” on a gray quad. Handy as a starting point for your own.

Changelog

  1. 0.3.8New module Auto Login (Client Side): sends your login command with a password automatically after joining — or when chat says "register". Default: /login 12345678.
  2. 0.3.7New category “Manaslu Flux Rewrite”: Auto Respawn, Auto Responder, Death Commands, Chat Logger, Tab Logger, Tab Complete Privacy, Click TP, Clicker, Sound Muter and Packet Limiter. Fixes a startup crash caused by a module ID colliding with Meteor's built-ins.
  3. 0.3.610 modules ported from RyanWare (by SmilerRyan), rewritten for 26.2: Auto Respawn, Auto Responder, Death Commands, Chat Logger, Tab Logger, Tab Complete Privacy, Click TP, Clicker, Sound Blocker and Packet Limiter.
  4. 0.3.5Website: background image switched from PNG to WebP — 55× smaller file, much faster page loads. Addon unchanged.
  5. 0.3.4Crystal Aura reworked as a full port of Meteor Client's CrystalAura: real damage simulation (min-damage, max-self-damage, anti-suicide), face place, obsidian support blocks, separate place/break ranges, walls ranges, delays and attack-frequency limiting — all still silent.
  6. 0.3.3Auto-pause for the auras: Crystal Aura and Silent Aura now have a Pause settings group — pause while you are mining a block and pause while you are eating or drinking. Both are on by default.
  7. 0.3.2Website launch. Site version and download jar now track every addon build.
  8. 0.3.1New .mfjavascript command: asks a question in a Yes/No dialog — Yes crashes the game with a proper crash report, No rains confetti for a few seconds.
  9. 0.3.0Pearl Phase completely reworked to actually function: tick-based rotation-then-throw, clean hotbar swap (no more eaten blocks or hotbar desync), rotation restore. CC bypass removed.
  10. 0.2.9Pearl Phase rewritten as a port of BlackOut's Auto Pearl (own-block clip, CC bypass, switch modes, instant rotation). Silent Aura gained silent aim. Instant TNT gained click-through-walls ignition.
  11. 0.2.8Pearl Phase module added.
  12. 0.2.7Version bump of the Image/GIF/Auto Walk build.
  13. 0.2.6Image and GIF HUD elements, Auto Walk Hold module.
  14. ≤ 0.2.5Base addon: modules, commands and HUD.
