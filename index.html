Commands

Type them in Meteor's command prompt. Click one to copy it.

HUD elements

Add them from the HUD editor, in the “Manaslu Flux” group.

Image

Shows a png, jpg, bmp or the first frame of a gif, from an absolute path or relative to .minecraft. Scale, opacity and smooth/nearest filtering.

GIF

Animated GIFs with each frame's real delay. Only re-uploads a frame when it changes. Same settings as Image.

Example

The template element: “ManasluFlux” on a gray quad. Handy as a starting point for your own.

Player List

A box with all the other players on the server, sorted by name or ping — color-coded ms, custom title, max rows. Drag and scale it in the HUD editor.

Server Info

Your server's name and address, online player count and your live latency, color-coded. Dark box, rows toggle individually.

Session Info

In-game day number, HH:MM clock, weather (Clear/Rain/Thunder) and the biome you are standing in — the same overworld clock the .mfday command uses.

Kill Counter

Session combat tracker: kills (players and/or hostile mobs, friends excluded), deaths and computed K/D. Auto-reset on world or dimension change.

Changelog

  1. 0.12.0New module Place Travel (place-travel): one-key travel for the nether roof. It holds forward and sprint, and jumps on the first tick you are back on the ground — the 10 tick jump cooldown is skipped, so the hops come out back to back. While you run it lays a straight line of blocks ahead of you, distance blocks in front (default 2), at the height you pick: Floor (default) keeps the level you are running on solid so a hole cannot drop you, while Feet / Head / Above head build the line over you. The line is pinned to the block level you last stood on, so it stays flat through the jump arc. Counts: 47 modules, Movement 6.
  2. 0.11.0New module Inventory Keeper (inventory-keeper): press the Save layout button on the module screen and the slots you have now become the reference. Every refresh-rate milliseconds (default 200, 0 = every tick) it re-reads the inventory and swaps any saved item back into its slot — the item sitting in the wrong place is swapped out to where the wanted one came from, so nothing is dropped and nothing leaves your inventory. only-hotbar keeps just the nine hotbar slots in order. Items that were used up or left in a chest are skipped, the checks only run with no screen open and an empty cursor so it never fights a drag, at most 8 swaps happen per check, and the layout is saved in the Meteor config so it survives restarts. Counts: 46 modules, Player 7.
  3. 0.10.1AC PacketFlood no longer waits for the game tick: place/break packets are fired by a continuous 1 ms loop, so place-delay-ms 1 is roughly 1000 packets per second per action and 0 bursts until max-packets-per-second is hit. Plans are still rebuilt each tick on the game thread; batches go out whole and the loop survives exceptions.
  4. 0.10.0New command .mffakeplayer — a fake player the client really believes is a player, unlike Meteor's .fake-player: it gets its own player-list entry (tab list, nametags, skins) and is registered in world.getPlayers() like a joining player, so auras, target finding and anything else that only reacts to real players picks it up. add [name], remove, clear, list, tp, health <hp>; it spawns where you look and copies your inventory so armor counts in damage.
  5. 0.9.0New module AC PacketFlood (`ac-pcktflood`): a crystal aura on the packet timeline — every place and break is a raw packet fired by a millisecond scheduler, with a packet delay in ms (default 1), per-action retries and retry delay (so the timeline reads 1ms:packet 3ms:retry 5ms:retry … 6ms:packet), bases-per-tick, all the usual aura settings and a max-packets-per-second cap. Retries stop the instant the server confirms with a spawn/destroy packet. Modules re-categorised: the old "Main" and "Rewrite" buckets are gone — Combat (8), Movement (5), Player (6), World (4), Client Side (9), Utility (13), each with its own tab icon.
  6. 0.8.1Every numeric setting now goes from 0 to 10000 — all 69 int and double settings across every module and HUD element, sliders included. A few internals are clamped so a dialled-up value can't freeze the game: the place/fill/through-walls block scans stop at 8 blocks radius (your range value still applies), the Discord RPC update interval is guarded against 0, and Auto Fish's look-up pitch is now a plain 0–10000 angle.
  7. 0.8.0Packet level for Crystal Aura and Auto Totem: both modules get a new Packet group. Packet level sends the interactions as raw packets and reads the server's answer from the packet stream instead of waiting for game ticks — Crystal Aura sends its own use-block/attack packets and pops a crystal the instant its spawn packet arrives, Auto Totem sends the two inventory click packets of the offhand swap itself (same millisecond, no inventory sync wait) and refills the moment the totem-pop packet lands. Both have packet retries (resend until the server visibly reacts) and a max-packets-per-second cap.
  8. 0.7.0New module: Discord RPC — fully customizable Rich Presence. One-click presets (Crystals, PvP, Mining, Exploring, Building, AFK), editable Line 1 / Line 2 with placeholders ({player}, {server}, {ping}, {pos}, {dimension}, {server}, {cps}, {version}, {health}), large image name & text, optional small image, elapsed-time timer, update interval, and a built-in crystals-per-second counter. Set your own Discord Application ID to change the name shown by Discord and use your own images (default: Meteor's app).
  9. 0.6.0Full port to Minecraft 1.21.11 + Meteor Client 1.21.11: every module, command, HUD element and both mixins re-mapped to the new API, the bundled Baritone swapped to the 1.21.11 Fabric build, and the Image/GIF HUD elements rewritten onto the new blaze3d texture path (async decoding). Nothing added or removed — this is the compatibility release.
  10. 0.5.3New Anti Drop Lagback module: counts rubberband corrections (server position syncs that snap you back) inside a time window, and when the cap is passed it pauses every other active module for a set amount of ticks so the cause stops — then resumes them. Chat notifier included.
  11. 0.5.2Crash fix: the Client Block Entities mixin declared a wrong parameter type, so the mixin failed at startup and crashed the game on launch (0.5.0/0.5.1). Now uses the exact descriptor and the game boots fine.
  12. 0.5.1New Auto Chat Clear module: automatically does the vanilla F3+D chat clear after every N received messages - keeps the backlogged chat empty on busy servers without manual keypresses. Scrollback history stays (optional wipe), nothing is sent to the server.
  13. 0.5.0New Client Block Entities module: pick any block entity types (chests, signs, beacons, spawners...) and their rendering becomes client-side only - replaced by a static box or hidden entirely, like Crystal Optimizer but for everything. The block itself still renders normally.
  14. 0.4.10Crash fix: opening the Meteor GUI in the main menu no longer crashes ("Components not bound yet" - category icons now use the same pre-bound item construction Meteor itself uses).
  15. 0.4.9Two new top-bar tabs in the Meteor GUI: Notepad (multiple free-text note pages) and To Do (checkbox task list with a n/m-done counter). Both save to disk and survive restarts.
  16. 0.4.8Three new HUD elements: Server Info (server/address + live ping), Session Info (in-game day, clock, weather, biome) and Kill Counter (session kills/deaths/K-D). HUD count 4 → 7.
