ManasluFlux

A Meteor Client addon with flight, silent combat, client-side tricks and a handful of tools you'll actually keep enabled.

Commands

Type them in Meteor's command prompt. Click one to copy it.

HUD elements

Add them from the HUD editor, in the “Manaslu Flux” group.

Image

Shows a png, jpg, bmp or the first frame of a gif, from an absolute path or relative to .minecraft. Scale, opacity and smooth/nearest filtering.

GIF

Animated GIFs with each frame's real delay. Only re-uploads a frame when it changes. Same settings as Image.

Example

The template element: “ManasluFlux” on a gray quad. Handy as a starting point for your own.

Player List

A box with all the other players on the server, sorted by name or ping — color-coded ms, custom title, max rows. Drag and scale it in the HUD editor.

Server Info

Your server's name and address, online player count and your live latency, color-coded. Dark box, rows toggle individually.

Session Info

In-game day number, HH:MM clock, weather (Clear/Rain/Thunder) and the biome you are standing in — the same overworld clock the .mfday command uses.

Kill Counter

Session combat tracker: kills (players and/or hostile mobs, friends excluded), deaths and computed K/D. Auto-reset on world or dimension change.

Changelog

  1. 1.9.4Universal Cobweb Bypass gets reset-on-new-web (default on). The graph timer's clock and the sprint tweaks' tick counter now restart as soon as you walk out of one cobweb into another — even when the two touch. "This web" is the set of web blocks that was under your box when you entered it, so a hop from web A into the touching web B (you straddle both for a few ticks) resets the moment A is gone, instead of the ramp carrying on across the whole corridor. Standing still in one web still counts up normally, and leaving into open air resets as before. Switch it off and the old behaviour comes back: the clock only restarts once you have been out of a web. Counts: 50 modules, 28 commands.
  2. 1.9.3New module: Break Reminder (break-reminder) — set interval in minutes (default 45, 0 = off, up to 10000) and it reminds you to stand up when that much time has passed, in chat and/or as the big title text on screen. The clock is wall-clock rather than tick-based, so it counts the same whatever the server is doing, and it restarts whenever you switch the module on. Counts: 50 modules, 28 commands.
  3. 1.9.2New module: Screenshot (screenshot) — puts a screenshot of the game straight on your clipboard instead of saving a file, so it can be pasted into Discord immediately. One-shot: bind a key, press it, the module switches itself back off. It grabs the frame through vanilla's own ScreenshotRecorder, so it matches an F2 screenshot exactly, and hands the clipboard write to its own thread because Windows can block there while other apps read the image; any failure is reported in chat. The Bypasses category is now named honestly: every module in it carries a Universal prefix, because none of them target one anticheat — universal-cobweb-bypass, universal-click-tp, universal-pearl-phase, universal-vclip-phasefill and universal-flight. Per-server differences live in settings (Cobweb Bypass keeps its Vanilla / NCP / Themis / Grim profiles), not in the module's name. Counts: 49 modules, 28 commands.
  4. 1.9.1New module: British Chat (british-chat) — tidies every message you send: a capital letter at the start (and after each sentence), a full stop at the end, and with grammar-correct on it fixes the words everyone mistypes mid-fight — missing apostrophes (dont, cant, wont, im), swapped letters (teh, adn, recieve) and chat shorthand (u, ur, pls, idk, ty, rn) — plus doubled spaces and spaces before punctuation. It rewrites the message before Meteor signs it, so the tidied text is what the server receives and nothing is sent twice. Commands are never touched, and a dot glued to lowercase (a hostname like mc.hypixel.net, or 3.5) is never treated as a sentence break. It is a fixed rule list rather than a language model, so unknown words pass through exactly as typed. Counts: 48 modules, 28 commands.
  5. 1.9.0New module: Bed Aura (mf-bed-aura) — places and pops beds in the Nether and the End and charged respawn anchors in the Overworld and the End, picking whichever the dimension lets explode and falling back to the other item when the first isn't in your inventory, so one module covers every dimension. Their bed geometry: rotate to a cardinal direction so the bed's head half lands on the target block, both halves must be free, then pop it with a plain use (an anchor pops with a glowstone-free use, so the glowstone you charged it with stays out of that hand). Settings: place-delay, target-range, min-damage, max-self-damage, anti-suicide, place-range, auto-switch, anchor-charges (1–4 glowstone), charge-delay, pause on eat/drink/mine, and a render box. Every numeric setting runs 0–10000. Counts: 47 modules, 28 commands.
  6. 1.8.0Graph timer gets a max-timer ceiling (default 10, 0 = no cap). It clamps the curve, so a steep formula or a big scale stops at the cap instead of handing the server a huge tick jump; Constant mode is untouched. .mfvisualizewebbypassgraph draws it as a green dashed line, and the samples are already clamped, so the chart shows the real ceiling.
  7. 1.7.0New command .mfvisualizewebbypassgraph. It opens your browser on a chart of the Cobweb Bypass timer: the multiplier over the first 20 seconds in a web, sampled from the module's own formula once every 0.05 s, so the picture always matches what the timer is doing. Chips carry the mode, formula, scale, web-timer and peak; a slider and pointer hover scrub the curve (1.00x at 0s, 8.44x at 3s, 9.60x plateau on the defaults); a formula that does not parse shows an error card instead of a fake curve. Counts: 46 modules, 28 commands.
  8. 1.6.4Graph scale default is 8.605, not the 8.0 that 1.6.3 shipped — the plateau is now 1 + 8.605 = 9.605x. Existing configs keep whatever value they already have.
  9. 1.6.3Cobweb Bypass now defaults to the tuned setup. A fresh install starts where the working combo ended: NCP profile, horizontal and vertical 100, max-speed 59.142, web-timer 1.35, on-lagback Notify with pause-ticks 0, sprint tweaks 2 / 1, and the graph timer with 1 - exp(-t / 1.5) at scale 8.0 (~9x plateau). Defaults only touch settings you never changed — your saved config keeps its values.
  10. 1.6.2Cobweb Bypass: the timer can follow a graph. timer-mode Graph (default) drives Meteor's Timer from graph-formula, an expression in t (seconds spent in the web), scaled by graph-scale (default 0.5): the speed is 1 + graph-scale × value, so a value of 0 is the normal 1x timer and a value of 1 is 2x at scale 1, 1.5x at 0.5. The default formula 1 - exp(-t / 1.5) is fast at first and then flattens — 1.24x at 1s, 1.43x at 3s, plateau 1.5x — and never slows back down. Constant keeps the old timer-multiplier. Any formula of t works (exp, log, sqrt, abs, min, max, floor, round and the usual operators); a broken one warns once and stays at 1x.
  11. 1.6.1New category: Bypasses. A seventh ClickGUI tab, Manaslu Flux Bypasses, holds the modules whose job is beating a server or anticheat check rather than changing what you do. Cobweb Bypass, Click TP, VClip PhaseFill and Universal Flight move there out of Movement, and Pearl Phase out of Combat. Same 46 modules, same 27 commands, same settings - only the tab they live in.
  12. 1.6.0Cobweb Bypass gets two new groups. Sprint Tweaks: stop-sprint-before releases your sprint a set number of ticks before a cobweb is ahead, and start-sprint-after holds sprint off inside a web until that many ticks have passed, then turns it back on while you are walking — applied before the player tick, and again after it, because a held sprint key would otherwise switch it straight off/on again. Timer: timer-multiplier runs Meteor's own Timer only while you actually stand in a cobweb and restores it the moment you leave, so nothing stays overridden.
  13. 1.5.0Crystal Aura is now a full port of BlackOut's Auto Crystal+, vendored unmodified in blackout/modules/AutoCrystalPlus.java. It takes their whole decision model: enemy / friend / self damage with health, the min-max ratio checks, force pop and anti-pop, Normal vs Safe damage checking, min place and explode damage, their place and explode speed models with a slow speed under a damage threshold, instant place / instant attack, six switch modes with a switch penalty, only-own / inhibit / existed / set-dead gates, and extrapolated hitboxes for damage and range checks. Not ported: ID Predict, the AutoMine/PistonCrystal compatibility group, and the three animated box styles. The old Meteor-style module and its Packet group are gone.
  14. 1.4.0Pearl Phase is now a full port of BlackOut's Auto Pearl, and BlackOut source files get vendored into a new blackout/ folder for future ports (the original AutoPearl.java unmodified, plus their GPL-3.0 license and a README recording the pinned commit and how their helpers map onto Meteor). The port keeps their behaviour: cc-bypass places a block under you before the throw with its own switch mode, and the pearl has four switch modes — Normal, Silent, PickSilent and InvSwitch — pulling from your hotbar or inventory and putting it back. Pitch 85 by default, instant rotation, keep rotation and swing.
  15. 1.3.2Cobweb Bypass gets a web-timer: a multiplier for walking inside webs that only touches the horizontal axes, so it speeds the walk up instead of throwing you out of the web. 1.0 (default) is off, 2.0 walks twice as fast, and it only applies while you are actually moving — before the max-speed cap, so the cap still decides what the server sees. The autoconfig pins it to 1.0 during a sweep and restores it after, so it keeps testing only the two percentages.
  16. 1.3.1.mfwebspeed verbose: the autoconfig now narrates itself. Add verbose to any form of the command and every combo prints [3/36] testing horizontal 40% / vertical 60% when it starts, then its verdict — -> OK - out in 3 tick(s), -> FAILED - the server pulled you back or -> stuck - never left the web. Off by default, so a normal sweep still only prints the final result.
  17. 1.3.0New command .mfwebspeed: autoconfig for Cobweb Bypass that measures instead of guessing. It takes your keys, walks you into the nearest cobweb and sweeps every horizontal × vertical pair from 0 up to the max you pass (in steps, default 20), timing how many ticks it takes to leave the web while holding forward and jump. A lagback during a combo marks that combo failed; the fastest pair with none is applied as Custom. negative also tries -5..-1 (off by default, so the sweep normally runs 0 → max), .mfwebspeed stop restores the old settings, and sweeps over 400 combinations are refused. Counts: 46 modules, 27 commands.
  18. 1.2.1Launch-crash fix. The mixin config still listed EndCrystalRendererMixin, a class deleted in 1.0.0 with Crystal Optimizer - mixin reads the config before anything else and a missing entry is fatal, so the game died on startup with InvalidMixinException (1.1.0 and 1.2.0 both shipped it). The config now lists exactly the two mixins that exist in the jar. Cobweb Bypass itself is unchanged.
  19. 1.2.0New module Cobweb Bypass (cobweb-bypass): no-slow in webs. Minecraft 1.21.11 does not slow your velocity directly any more - slowMovement stores a multiplier (0.25 / 0.05 / 0.25 for cobwebs) that the movement step applies to the tick's delta - so the module swaps that single number for a softened one, entirely client-side. horizontal / vertical are percent of the slow removed (100 = no slow at all), max-speed caps the per-axis step, burst-ticks softens only the first ticks in a web, and all-stuck-blocks covers more than cobwebs. Profiles: Vanilla (full speed - servers that never simulate webs), NCP, Themis, Grim (short burst only, since Grim re-simulates webs itself) and Custom. A lagback watcher reports correction teleports that follow the trick and can drop back to vanilla slow for pause-ticks. Counts: 46 modules, Movement 8.
  20. 1.1.0New module VClip PhaseFill (vclip-phasefill): the phase-fill trick in one one-shot module. Turning it on vclips you distance blocks (default 3) straight Down or Up, then fills the blocks your body was standing in before the clip — feet and head, taken from your hotbar, blocks-per-tick each tick and retried until they land — and waits for the server's rubberband correction. hold-position keeps re-applying the clipped spot while waiting, because the client pushes an entity out of a solid block on its own. If no rubberband arrives within timeout ticks (default 20, 0 = right away) it vclips you back to where you started. Counts: 45 modules, Movement 7.
  21. 1.0.0First stable release. AC PacketFlood and Crystal Optimizer are gone, along with the 1 ms packet scheduler and the end-crystal render mixin that only existed to serve them - Crystal Aura and Auto Totem keep their own packet level, retries and packet cap. Add Text stopped being a module: .mfaddtext <text> is now a chat command that prints a line only for you and sends nothing, with no stored list between sessions. Counts: 44 modules (Combat 7, Movement 6, Player 7, World 4, Client Side 8, Utility 12), 26 commands, 7 HUD elements.
  22. 0.12.0New module Place Travel (place-travel): one-key travel for the nether roof. It holds forward and sprint, and jumps on the first tick you are back on the ground — the 10 tick jump cooldown is skipped, so the hops come out back to back. While you run it lays a straight line of blocks ahead of you, distance blocks in front (default 2), at the height you pick: Floor (default) keeps the level you are running on solid so a hole cannot drop you, while Feet / Head / Above head build the line over you. The line is pinned to the block level you last stood on, so it stays flat through the jump arc. Counts: 47 modules, Movement 6.
  23. 0.11.0New module Inventory Keeper (inventory-keeper): press the Save layout button on the module screen and the slots you have now become the reference. Every refresh-rate milliseconds (default 200, 0 = every tick) it re-reads the inventory and swaps any saved item back into its slot — the item sitting in the wrong place is swapped out to where the wanted one came from, so nothing is dropped and nothing leaves your inventory. only-hotbar keeps just the nine hotbar slots in order. Items that were used up or left in a chest are skipped, the checks only run with no screen open and an empty cursor so it never fights a drag, at most 8 swaps happen per check, and the layout is saved in the Meteor config so it survives restarts. Counts: 46 modules, Player 7.
  24. 0.10.1AC PacketFlood no longer waits for the game tick: place/break packets are fired by a continuous 1 ms loop, so place-delay-ms 1 is roughly 1000 packets per second per action and 0 bursts until max-packets-per-second is hit. Plans are still rebuilt each tick on the game thread; batches go out whole and the loop survives exceptions.
  25. 0.10.0New command .mffakeplayer — a fake player the client really believes is a player, unlike Meteor's .fake-player: it gets its own player-list entry (tab list, nametags, skins) and is registered in world.getPlayers() like a joining player, so auras, target finding and anything else that only reacts to real players picks it up. add [name], remove, clear, list, tp, health <hp>; it spawns where you look and copies your inventory so armor counts in damage.
  26. 0.9.0New module AC PacketFlood (`ac-pcktflood`): a crystal aura on the packet timeline — every place and break is a raw packet fired by a millisecond scheduler, with a packet delay in ms (default 1), per-action retries and retry delay (so the timeline reads 1ms:packet 3ms:retry 5ms:retry … 6ms:packet), bases-per-tick, all the usual aura settings and a max-packets-per-second cap. Retries stop the instant the server confirms with a spawn/destroy packet. Modules re-categorised: the old "Main" and "Rewrite" buckets are gone — Combat (8), Movement (5), Player (6), World (4), Client Side (9), Utility (13), each with its own tab icon.
  27. 0.8.1Every numeric setting now goes from 0 to 10000 — all 69 int and double settings across every module and HUD element, sliders included. A few internals are clamped so a dialled-up value can't freeze the game: the place/fill/through-walls block scans stop at 8 blocks radius (your range value still applies), the Discord RPC update interval is guarded against 0, and Auto Fish's look-up pitch is now a plain 0–10000 angle.
  28. 0.8.0Packet level for Crystal Aura and Auto Totem: both modules get a new Packet group. Packet level sends the interactions as raw packets and reads the server's answer from the packet stream instead of waiting for game ticks — Crystal Aura sends its own use-block/attack packets and pops a crystal the instant its spawn packet arrives, Auto Totem sends the two inventory click packets of the offhand swap itself (same millisecond, no inventory sync wait) and refills the moment the totem-pop packet lands. Both have packet retries (resend until the server visibly reacts) and a max-packets-per-second cap.
  29. 0.7.0New module: Discord RPC — fully customizable Rich Presence. One-click presets (Crystals, PvP, Mining, Exploring, Building, AFK), editable Line 1 / Line 2 with placeholders ({player}, {server}, {ping}, {pos}, {dimension}, {server}, {cps}, {version}, {health}), large image name & text, optional small image, elapsed-time timer, update interval, and a built-in crystals-per-second counter. Set your own Discord Application ID to change the name shown by Discord and use your own images (default: Meteor's app).
  30. 0.6.0Full port to Minecraft 1.21.11 + Meteor Client 1.21.11: every module, command, HUD element and both mixins re-mapped to the new API, the bundled Baritone swapped to the 1.21.11 Fabric build, and the Image/GIF HUD elements rewritten onto the new blaze3d texture path (async decoding). Nothing added or removed — this is the compatibility release.
  31. 0.5.3New Anti Drop Lagback module: counts rubberband corrections (server position syncs that snap you back) inside a time window, and when the cap is passed it pauses every other active module for a set amount of ticks so the cause stops — then resumes them. Chat notifier included.
  32. 0.5.2Crash fix: the Client Block Entities mixin declared a wrong parameter type, so the mixin failed at startup and crashed the game on launch (0.5.0/0.5.1). Now uses the exact descriptor and the game boots fine.
  33. 0.5.1New Auto Chat Clear module: automatically does the vanilla F3+D chat clear after every N received messages - keeps the backlogged chat empty on busy servers without manual keypresses. Scrollback history stays (optional wipe), nothing is sent to the server.
  34. 0.5.0New Client Block Entities module: pick any block entity types (chests, signs, beacons, spawners...) and their rendering becomes client-side only - replaced by a static box or hidden entirely, like Crystal Optimizer but for everything. The block itself still renders normally.
  35. 0.4.10Crash fix: opening the Meteor GUI in the main menu no longer crashes ("Components not bound yet" - category icons now use the same pre-bound item construction Meteor itself uses).
  36. 0.4.9Two new top-bar tabs in the Meteor GUI: Notepad (multiple free-text note pages) and To Do (checkbox task list with a n/m-done counter). Both save to disk and survive restarts.
  37. 0.4.8Three new HUD elements: Server Info (server/address + live ping), Session Info (in-game day, clock, weather, biome) and Kill Counter (session kills/deaths/K-D). HUD count 4 → 7.
