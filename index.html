Commands

Type them in Meteor's command prompt. Click one to copy it.

HUD elements

Add them from the HUD editor, in the “Manaslu Flux” group.

Image

Shows a png, jpg, bmp or the first frame of a gif, from an absolute path or relative to .minecraft. Scale, opacity and smooth/nearest filtering.

GIF

Animated GIFs with each frame's real delay. Only re-uploads a frame when it changes. Same settings as Image.

Example

The template element: “ManasluFlux” on a gray quad. Handy as a starting point for your own.

Player List

A box with all the other players on the server, sorted by name or ping — color-coded ms, custom title, max rows. Drag and scale it in the HUD editor.

Server Info

Your server's name and address, online player count and your live latency, color-coded. Dark box, rows toggle individually.

Session Info

In-game day number, HH:MM clock, weather (Clear/Rain/Thunder) and the biome you are standing in — the same overworld clock the .mfday command uses.

Kill Counter

Session combat tracker: kills (players and/or hostile mobs, friends excluded), deaths and computed K/D. Auto-reset on world or dimension change.

Changelog

  1. 1.15.5Update detector with an Update & restart button. ManasluFlux now checks the site every 30 seconds for a newer release. When there is one, a window opens with the installed and latest version and a single Update & restart button (plus .mfupdate): it downloads the new jar, refuses anything whose fabric.mod.json is not ManasluFlux at that exact version, renames every old manasluflux-*.jar to .disabled, swaps the new one in and restarts the game with the same command line. If the button is never pressed the update is forced 10 minutes after the version was first seen, and the window shows that countdown. Clicking Later leaves the countdown running. Counts: 65 modules, 30 commands.
  2. 1.15.4Custom ESP draws the model, not the hitbox. style: Model (default) sends each selected entity through Meteor's WireframeEntityRenderer - the call Meteor's own ESP makes for its wireframe mode - so the outline is the entity's real model quads: head, arms, legs, wings, every part posed and rotated, moving as it walks. The Block Highlight look stays: fill with the side alpha, and a glow halo that in Model style is the same model scaled slightly larger, so it hugs the shape instead of box-bloating around it. style: Box keeps the old hitbox drawing, and that is where line-thickness still applies (a model's edges are its own quads, always one pixel). Fades are unchanged; a fade-out falls back to the last hitbox, since a dead entity has no render state left. Counts: 65 modules, Client Side 13.
  3. 1.15.3New module: Custom ESP (custom-esp, Client Side) - ESP where you pick the entities like normal (an entity-type list, players by default) and every match is drawn with Block Highlight's box: fill whose alpha comes from side-color, real line-thickness (edges drawn as thin boxes, since Meteor's lines are one pixel), and a glow halo of glow-layers shells spread over glow-spread at glow-strength. Boxes fade in when an entity appears and fade out from their last box when it dies or leaves, and they follow the entity's interpolated hitbox. Counts: 65 modules, Client Side 13.
  4. 1.15.2New module: XCarry (xcarry, Player) - four extra storage slots in your 2x2 crafting grid. The CloseHandledScreenC2SPacket for your own player handler is held back while the grid (slots 1-4) holds anything, so the server never empties it and the slots stay live: press E again and the items are still in the grid. Chests, shulkers and anvils close normally (different sync id), an empty grid closes like vanilla, and switching the module off sends the real close so the items come back to your inventory. chat-feedback reports both directions; the info string reads storing while it is holding. Counts: 64 modules, Player 9.
  5. 1.15.1Self Mine Out now holds the pickaxe itself. It used to hand the block to Speed Mine and never touch your hand, so the mine ran with whatever slot you happened to be on. It now picks the hotbar slot with the highest break delta for the block about to go (BlockUtils.getBreakDelta over slots 1-9) and puts it in your hand before the block is requested. tool-switch is Silent by default - one UpdateSelectedSlotC2SPacket, so the server believes you are on the pickaxe while your hotbar keeps the slot it is on - or Visible (also selects the slot, restored afterwards) or None (the old behaviour). The hand goes back the moment both the head and feet blocks are clear, and on disable, so nothing is left over after a phase. Counts: 63 modules.
  6. 1.15.0New module: Silent Timer Switch (mf-silent-switch, Bypasses) - a held-item switch on a timer. item is what it switches to (an item picker, default totem of undying), every is how often in ticks (default 60 = 3 s, 20 ticks = 1 s) and hold is how long it stays switched (default 10 ticks). mode: Silent (default) is one UpdateSelectedSlotC2SPacket and nothing else, so the server believes you hold the item for the hold time while your client keeps the slot it was already on - the hotbar never moves - and Visible moves your real slot and puts it back. Hotbar slots 1-9 only (the protocol can only select those), it skips the slot you are already on, and it restores the slot on disable too, so turning it off mid-hold cannot leave the server on the wrong item. The info string shows the chosen item. Counts: 63 modules, Bypasses 10.
  7. 1.14.0Two more Sydney ports, and a crash fix that was ours. Kill Say (kill-say, Combat) is Sydney's KillSayModule: a message when you kill a player, optional pop announcements, delay between messages, clientside, green-text, kill-streak, suicide-ignore, and Default/Custom message lists (Sydney's files became editable string lists in the config). FOV Modifier (fov-modifier, Client Side) is Sydney's FOVModifierModule: forces the FOV you pick, with its 70° fixed-pass guard behind items, driven by Meteor's own FOV event. And the crash: Meteor's Modules.add evicts any module with the same id, and four of ours shared Meteor's ids — auto-totem, auto-eat, auto-fish, auto-log — which deleted Meteor's own modules from the registry and made Meteor's AutoReplenish NPE at join. They are now mf-auto-totem, mf-auto-eat, mf-auto-fish, mf-auto-log: Meteor's versions come back and no id collides any more (checked against all 165 Meteor ids). Renaming those four resets their saved settings and keybinds once. Counts: 62 modules, Combat 9, Client Side 12.
  8. 1.13.1Surround actually places blocks now, and stops flooding the server. The hotbar swap moved inside Meteor's rotation callback: it used to be swapped before the rotation was queued and restored straight after, so the placement packet went out with your original item, the server ignored it, the same spots were re-queued every tick and those queued rotations — one look packet each — tripped HaZey's You are sending too many packets kick. Placement is now serialized to one spot per tick (limit still counts a group, delay still separates groups) because Meteor carries a single rotation per tick; a spot that was placed into is left alone for 100 ms so it is not filled twice before the server confirms it; timing: Sequential still rebuilds a spot the moment a crystal spawns into it. The await setting is gone — every placement already waits for the previous one.
  9. 1.13.0New module: Surround (mf-surround, Combat) - port of Sydney's SurroundModule (sydney-client/Sydney-Legacy, GPL-3.0, original vendored in sydney/) together with the hole geometry it takes its feet positions from (HoleUtils#getFeetPositions). It blocks your feet: the block you stand in plus its four sides, extension adding every column an entity occupies, floor adding the block below each, everything filtered by range and by "replaceable with nothing standing in it". It uses the hardest block in your hotbar (switch: None / Silent / Normal), places limit (default 4) per group with delay ticks between groups, clicks the first solid neighbour (or only a side facing you with strict-direction), places the block under a spot first and retries the spot itself on the next tick when there is nothing to click, and destroys crystals sitting in a spot (crystal-destruction). timing: Sequential (default) rebuilds a spot the moment a crystal spawns into it, Vanilla waits for the next group. Disable group: self-disable, jump-disable (fall > 2 blocks or a Y change), item-disable, step-toggle; center snaps you into the block, render draws the spots. Three Sydney details cannot exist on 1.21.11 and are documented in the vendored README: the HitboxDesync interaction, the shift-press packet, and Sydney's mock-crystal Sequential attack - the port attacks the real entity by id a tick later instead of sending an id the server does not know. Counts: 60 modules, Combat 8.
  10. 1.12.4Auto Crystal aims itself. Placement was gated by a raycast along your own camera - the port's crystalHit walked your yaw/pitch out six blocks and refused unless it hit the base, so the aura only placed on a block you were literally looking at, and Meteor's BlockUtils.interact sent that same look. The gate is gone: reach decides placement now, and the aura turns to the exact click point before every crystal place, to each queued obsidian place, and to the crystal before every break (the attack packet follows the rotation). look (default on) can be switched off to use your own aim, and silent (default on) keeps the turn server-side - with it off the camera really moves to the spot. Not a port change: Homovore rotated through its own rotation manager, so this restores that behaviour. Counts unchanged: 59 modules.
  11. 1.12.3Auto Crystal: renamed, and it breaks crystals now. The Homovore port is called Auto Crystal (auto-crystal) like the original, instead of Homovore Crystal. Two fixes inside it: every break was an attack on your own player (the target argument came over from the old BlackOut aura), which the server answered with Cannot interact with self! and a kick - the packet now targets the crystal, on both the tick break and the spawn-packet break; and the separate instant-break toggle is gone, that path simply runs whenever break-delay is 0, as in the original. Render is Homovore's own again, all five modes: Gradient (default), GradientSmooth, BoxSmooth, Pulse and None, with gradient-height, pulse-color, render-time, smoothness, pulse-speed, pulse-expand, and line-width for real edge thickness - Meteor's line renderer is one pixel, so a non-zero width is drawn as thin boxes, and the gradient walls get a top ring and four corner edges at that width. An attack is also only sent while that crystal is still present client-side, because the server disconnects on an entity id it does not know. Counts unchanged: 59 modules.
  12. 1.12.2Block Highlight: side alpha and line thickness. fill (default on) fills the faces of the box from side-color, whose alpha channel is the side alpha - 45 of 255 by default, 0 for a pure outline - so the box has a readable interior without hiding the block. line-thickness (default 0.02 blocks, range 0-0.10, 0 = off) gives the outline real weight: Meteor's line renderer is always one pixel wide, so above 0 every edge is drawn as a thin cuboid instead (12 edges, sides only), and the glow shells use the same wire so the halo and the outline match. Glow default strength eased to 0.35 with a gentler falloff, since the shells now sit over a filled box. Counts unchanged: 59 modules, 29 commands.
  13. 1.12.1New module: Block Highlight (block-highlight), Client Side - port of Homovore's BlockHighlightModule (leonetics/homovore-public, AGPL-3.0) with a glow added. The box on the block you look at is animated the way theirs is: one block to the next morphs the box (every corner lerps over 60 ms, smoothstep eased, with a 20% pinch at the halfway point so it reads as moving), looking away fades it out from wherever it had got to, looking back fades it in from the same point, and a retarget mid-transition restarts the morph from the current animated box - so flicking across blocks never jumps. Five states drive it and the vanilla hit outline is hidden while it runs. The glow is new: glow (default on) draws glow-layers translucent shells (default 3) around the box, each glow-spread blocks further out (default 0.12) and weaker than the one inside it, so the halo falls off toward the edge; glow-strength sets the innermost shell's alpha. It fades and pinches with the box, and it is drawn with Meteor's renderer rather than a post-process pass, so there is no shader to break. Counts: 59 modules, 29 commands.
  14. 1.12.0Crystal Aura replaced with a full port of Homovore's AutoCrystal (homovore-crystal, Combat), vendored unmodified in homovore/ next to its PlacementManager - AGPL-3.0, same upstream as mf-speed-mine. The BlackOut crystal-aura is gone. Everything that makes Homovore's aura different is in: base place (work below the target layer by layer, place the obsidian yourself, crystal it); anti-chinese (answer a burrow - only crystal or break next to a redstone block, piston, sticky piston, piston head or moving piston); damage sync (skip a target still in the invulnerability window with full armour and turtle master); crystal tracking (a placement is remembered for 1.75 s and re-preferred while pending or alive); instant break from the spawn packet, before the next tick; and anti-surround, which ignores blocks Speed Mine is partway through (SpeedMine#collectMiningPositions) so a target behind a block that is about to vanish is not written off. Damage is the vanilla explosion model through Meteor's DamageUtils with Homovore's exposure rules - only blast resistance 600+ shadows, a base about to be placed counts as obsidian - min-damage divided by 4 under 20% health or with broken armour, and no-self-pop at 1.5 hearts. Placement is the ported PlacementManager: one queue, one silent swap per batch, 9 per 300 ms, 50 ms per block. Targets moved onto the aura (players / hostiles / neutrals / passives / ignore-friends, Meteor friends respected). Render is Meteor's renderer: None / Box (smoothed) / Pulse, plus debug scan time and packet-log peaks. Counts unchanged: 58 modules, 29 commands.
  15. 1.11.9New module: no-force-rotation (No Force Rotation), Player category. Server rotations arrive inside PlayerPositionLookS2CPacket - the setback packet, and what servers use to snap your view after a teleport or region change. Putting your camera back is not enough on its own, because the client acknowledges the forced angle. This rewrites the packet before the client handles it: position and velocity exactly as sent, yaw and pitch swapped for the ones you are looking at, then the rebuilt packet goes to the normal handler - so the acknowledgement carries your rotation. Relative flags (Y_ROT/X_ROT) carry a delta and get 0 instead of an absolute angle. yaw and pitch are separate toggles, and ignore-teleports (default 1 block, 0 = never) stands down when the packet also moved you further than that, because a big move is a real teleport and fighting its rotation usually earns a second setback. HUD shows blocked rotations / skipped teleports. Note: Meteor has a built-in no-rotate that does both axes with no options; this is the per-axis version with the teleport escape. Counts: 58 modules, 29 commands.
  16. 1.11.8New module: universal-self-mine-out (Self Mine Out). When a phase leaves you standing inside blocks, it mines you back out: the block your head is inside and the block your feet are inside are found from your bounding box and handed to Speed Mine, so they clear at tool speed instead of by holding left click inside a wall. head and feet are separate toggles; only blocks with collision count, so torches, signs and water are ignored; delay (2 ticks) stops it re-asking while a block is breaking; it works the same after a pearl or a vclip, and does nothing in the open. It drives Speed Mine (it is the miner), so with mf-speed-mine off it says so once in chat rather than silently idling. Counts: 57 modules, Bypasses 9, 29 commands.
  17. 1.11.7New module: mf-speed-mine (Speed Mine) - a port of Homovore's SpeedMine (leonetics/homovore-public, AGPL-3.0, original vendored unmodified in homovore/). Your click is cancelled and the break runs on our own packets: the start goes out with the best tool held, progress is predicted from the real break delta, and the stop follows as soon as it passes threshold (0.7). grim-decoy adds a second block-start 2000 blocks below the world so the pair Grim sees does not read as one impossibly fast break, and a 275 ms delay budget keeps the cadence inside what the server tolerates. double-break demotes a break to a second slot so a new click starts immediately, break-ahead also mines the block your ray continues into (rejected on corner grazes), rebreak keeps re-sending the stop, pause-on-eat never swaps mid-gap, plus break-delay, swing, range and a shrinking render box. The id is mf-speed-mine because Meteor ships its own SpeedMine. License: Homovore is AGPL-3.0, so a distributed build with this port is an AGPL-3.0 work (GPLv3 section 13). Also fixed: the command list was missing a separator after one entry, so the page threw at that line and two commands never rendered - all 29 now do. Counts: 56 modules, 29 commands.
  18. 1.11.6New module: totempoppearlphase (Totem Pop Pearl Phase). When your own totem pops - read from the server as USE_TOTEM_OF_UNDYING for your entity, the same signal that plays the animation - it throws one pearl after delay ticks (default 2), so the panic turn after a pop is a phase instead of a scramble. If a frame or painting is inside you (its box intersects yours) and frame-bypass is on, it aims at the clear band around it - a corner or edge of the face it hangs on, outside its 12/16-wide box, offset 0.46, pitch 85 - and only uses a point that is outside every decoration box (grown by the pearl 0.125 radius) and within reach, so a fully covered face falls back to the plain throw rather than feeding the frame a pearl. Nothing inside you means plain BlackOut own-block aim. The rotation goes out as a look packet, stable-cam (default on) puts your view straight back in the same tick, the pearl comes from your hand or silently from your hotbar, and it repeats on every pop. Counts: 55 modules, Bypasses back to 8, 29 commands.
  19. 1.11.5The item-frame phase modules are gone; in their place is the plain thing they were wrapping: universal-jump-pearl. It sneaks, jumps, and throws the pearl at jump-percent (default 55) of the jump - measured against the real vanilla arc (0.42 blocks/tick up, 0.08 gravity, 0.98 drag, peak 1.2522 blocks), so 55% is about 0.69 blocks off the ground rather than an arbitrary tick, and 0 throws on takeoff. If the jump cannot get that high (ceiling, slab, low gravity) it says so and spends no pearl. Aim is BlackOut's Auto Pearl one (own block centre turned 180 degrees, pitch 85), the rotation goes out as a look packet, and stable-cam (default on) puts your view straight back in the same tick so the screen never snaps - off, the camera stays turned at the throw. Also fixed: two module entries in the site data were missing a separator and were being parsed as one. Counts: 54 modules, 29 commands.
  20. 1.11.4Item-frame phase is now an actual frame-aware pearl phase (ncp-itemframe, th-itemframe). The old version pushed you with position packets, which was the wrong tool: pearl phase is what a frame breaks, because an item frame's box is 12/16 wide and 1/16 thick in front of the face, vanilla lets a pearl hit it, and the server owns the pearl — so a hidden frame client-side changes nothing. Both modules now throw the pearl at a point in the band around the frame (the frame covers the middle 0.375 of the face, the face ends at 0.5) with BlackOut's steep pitch, try up to 8 points (corners then edges), and measure every throw: a position packet means the server moved you, nothing means the next point. Points whose ray crosses a frame box are skipped by geometry before a pearl is spent, a fully covered face (map frame) is reported instead of thrown at, and aim OwnBlock is plain BlackOut pearl phase as the fallback. NCP sends its rotation 2 ticks early and answers in 8; Themis throws on the same tick and waits 14. Counts: 55 modules, 29 commands.
  21. 1.11.3Cobweb Bypass now reacts to repeated rubberbands. New lagback-limit (default 2, 0 = off) counts the server's setbacks per cobweb: once it has pulled you back more than that many times in the same web, the module reacts once — lagback-reset-timer (default on) restarts the web clock so the graph timer climbs from 1x again, and lagback-stop-sprint (default on) takes sprint away for the rest of that web, where neither the sprint tweaks nor a held sprint key can put it back until you leave. The count starts over when you enter a different web, following reset-on-new-web, so touching cobwebs count separately. verbose prints the rule you configured and every reaction. Counts: 55 modules, 29 commands.
  22. 1.11.2Wool Replace is now packet-only. universal-wool-replace drops the mode setting, the wool requirement and the hotbar swap: it hooks ClientConnection#send, and when the outgoing packet is an obsidian placement it writes a wool creative-inventory packet immediately before it and puts your real stack back immediately after — the server sees wool, nothing else is checked or changed. Your client inventory is untouched, so you still predict and see obsidian while the server stores wool: that mismatch is the glitch block. The only condition left is the one that defines the module — the packet has to be placing obsidian — with no position, distance, target or "around your feet" test. Creative-inventory packets are ignored by survival servers, so on survival it does nothing. Counts: 55 modules, 29 commands.
  23. 1.11.1Wool Replace moves to Bypasses and no longer needs wool. No wool in your inventory, nothing to select, and still no position/distance/target checks: while it is on, an obsidian placement is a wool placement, everywhere. mode Hotbar stays as the survival path (swap to wool you carry).   24. 1.11.0New modules: NCP and Themis item-frame phase (ncp-itemframe, th-itemframe). Sneak, jump, then push yourself into the block you face with position packets — NCP pacing sends 0.05-block steps one per tick (each step a distance a real tick could produce, with room for the server to answer), Themis pacing sends fewer 0.25-block steps in one tick to read as a single Step rather than Blink. mode Normal uses your look direction, Frame phases into the block an item frame hangs on; a setback during the attempt counts as a failure and it retries. Silent rotation (look packets, camera untouched) and optional silent hotbar switch. Honest note: research found item frames are only a targeting box, not movement collision, and no verified frame-specific phase exists for 1.21 — this is a generic stepped phase that ignores frames, paced from what NCP and Themis publicly check, not a proven bypass.   25. 1.10.3New module: Wool Replace (wool-replace) — places wool while you are holding obsidian. Right-click a block with obsidian in hand and the placement goes out as wool; your obsidian is selected again the moment the click is done. No settings, no position or target checks — it just does that while enabled. It has to swap the hotbar slot rather than edit the packet, because the placement packet carries only the hand, hit result, sequence and screen-handler revision — not the item; the server decides what to place from the item it thinks you hold. A mixin swaps in the wool slot at the head of interactBlock so vanilla builds and predicts a wool placement (no ghost block), then swaps back. Requires wool in your hotbar — with none, the click stays an obsidian placement, because there is no honest way to fake the held item. Counts: 53 modules, 29 commands.
  26. 1.10.2Universal Cobweb Bypass gets a verbose mode (default off).   27. 1.10.1New module: Packet Stealer (packet-stealer) — records everything the server sends your client about one player, with ISO-8601 UTC timestamps, into .minecraft/manasluflux/packetstealer/<name>.json (one JSON object per line, so a crash mid-session doesn't corrupt it). Worth being straight about the premise: a vanilla client never receives another player's packets — the server only broadcasts the effects of what they did, so that is what gets captured: movement and teleports, velocity, swings and criticals, totem pops and death, damage with its source, equipment changes (what they are holding) and optionally raw data-tracker updates. target is a name, or empty to pick the nearest player within range when you switch it on; movement is off by default (~20 lines a second), equipment on, data-tracker off. Counts: 52 modules, 29 commands.
  28. 1.10.0New module: Packet Filter (packet-filter) and new command .mfpacketlimit. The module holds a packets-per-second budget and drops the least important packet first instead of whatever arrives next: placing obsidian/crystals, breaking crystals, totem swaps, swings and inventory clicks are critical and never dropped; movement drops only once the budget is stretched a quarter past its limit; chat, sprint/sneak state and custom payloads go first. preset CPvP ranks a fight's packets top, Generic keeps only inventory/use/respawn critical. The command: .mfpacketlimit test [packets-per-tick] floods the server with look packets until it kicks you and reports how many went out and how fast (it will disconnect you — that is the measurement — and it stops itself after 60 s), and .mfpacketlimit check prints the budget, preset, sent/filtered/peak per second plus the last test's result, which survives the kick. Counts: 51 modules, 29 commands.
  29. 1.9.4Universal Cobweb Bypass gets reset-on-new-web (default on). The graph timer's clock and the sprint tweaks' tick counter now restart as soon as you walk out of one cobweb into another — even when the two touch. "This web" is the set of web blocks that was under your box when you entered it, so a hop from web A into the touching web B (you straddle both for a few ticks) resets the moment A is gone, instead of the ramp carrying on across the whole corridor. Standing still in one web still counts up normally, and leaving into open air resets as before. Switch it off and the old behaviour comes back: the clock only restarts once you have been out of a web. Counts: 50 modules, 28 commands.
  30. 1.9.3New module: Break Reminder (break-reminder) — set interval in minutes (default 45, 0 = off, up to 10000) and it reminds you to stand up when that much time has passed, in chat and/or as the big title text on screen. The clock is wall-clock rather than tick-based, so it counts the same whatever the server is doing, and it restarts whenever you switch the module on. Counts: 50 modules, 28 commands.
  31. 1.9.2New module: Screenshot (screenshot) — puts a screenshot of the game straight on your clipboard instead of saving a file, so it can be pasted into Discord immediately. One-shot: bind a key, press it, the module switches itself back off. It grabs the frame through vanilla's own ScreenshotRecorder, so it matches an F2 screenshot exactly, and hands the clipboard write to its own thread because Windows can block there while other apps read the image; any failure is reported in chat. The Bypasses category is now named honestly: every module in it carries a Universal prefix, because none of them target one anticheat — universal-cobweb-bypass, universal-click-tp, universal-pearl-phase, universal-vclip-phasefill and universal-flight. Per-server differences live in settings (Cobweb Bypass keeps its Vanilla / NCP / Themis / Grim profiles), not in the module's name. Counts: 49 modules, 28 commands.
  32. 1.9.1New module: British Chat (british-chat) — tidies every message you send: a capital letter at the start (and after each sentence), a full stop at the end, and with grammar-correct on it fixes the words everyone mistypes mid-fight — missing apostrophes (dont, cant, wont, im), swapped letters (teh, adn, recieve) and chat shorthand (u, ur, pls, idk, ty, rn) — plus doubled spaces and spaces before punctuation. It rewrites the message before Meteor signs it, so the tidied text is what the server receives and nothing is sent twice. Commands are never touched, and a dot glued to lowercase (a hostname like mc.hypixel.net, or 3.5) is never treated as a sentence break. It is a fixed rule list rather than a language model, so unknown words pass through exactly as typed. Counts: 48 modules, 28 commands.
  33. 1.9.0New module: Bed Aura (mf-bed-aura) — places and pops beds in the Nether and the End and charged respawn anchors in the Overworld and the End, picking whichever the dimension lets explode and falling back to the other item when the first isn't in your inventory, so one module covers every dimension. Their bed geometry: rotate to a cardinal direction so the bed's head half lands on the target block, both halves must be free, then pop it with a plain use (an anchor pops with a glowstone-free use, so the glowstone you charged it with stays out of that hand).   45. 1.3.0New command .mfwebspeed: autoconfig for Cobweb Bypass that measures instead of guessing.   47. 1.2.0New module Cobweb Bypass (cobweb-bypass): no-slow in webs. Profiles: Vanilla (full speed - servers that never simulate webs), NCP, Themis, Grim (short burst only, since Grim re-simulates webs itself) and Custom. A lagback watcher reports correction teleports that follow the trick and can drop back to vanilla slow for pause-ticks. Counts: 46 modules, Movement 8.
